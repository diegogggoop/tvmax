# tvmax

La misma lista de 80 canales con **la mayor calidad que da cada emisión, sin límite** (hasta 1080p, alguno más).
Pensada para decodificación de vídeo por hardware. Todas las fuentes son emisiones oficiales o plataformas gratuitas.
